# MY UNIVERSE — 나의 성장 포트폴리오

중학생을 위한 개인 포트폴리오 웹사이트입니다. HTML/CSS/JavaScript 한 파일로 구성되어 별도의 설치나 빌드 과정이 필요 없습니다.

## 포함된 기능
- 나를 소개하는 히어로 섹션과 관심 분야
- 이력 및 학교 활동 타임라인
- 상장·자격증·수료증 기록
- 프로젝트 쇼케이스
- 관심 스킬 트리
- 반응속도 테스트와 암산 미니 게임
- 별도 `tetris/index.html`에 포함된 BLOCK DROP 테트리스 게임
- 별도 `run3/index.html`에 포함된 VOID RUN 우주 러너 게임 (Run 3에서 영감을 받은 오리지널 게임)
- 기록 추가 모달
- 브라우저 로컬 저장 및 JSON 백업 다운로드
- 모바일 화면 대응

## 테트리스 게임
포트폴리오 프로젝트 영역에서 **테트리스 플레이하기**를 누르면 `tetris/index.html`의 게임을 새 탭에서 실행합니다. 게임 원본은 `egiby4/tetris` 저장소의 `index.html`을 가져와 포트폴리오 안에 배치했습니다.

## 기록 업데이트하기
1. 웹사이트에서 **＋ 기록 추가**를 누릅니다.
2. 기록 종류를 선택하고 제목, 날짜, 설명, 태그를 입력합니다.
3. **기록 저장하기**를 누르면 해당 브라우저에 저장됩니다.
4. 상단의 **백업 ↓** 버튼으로 기록을 JSON 파일로 내려받아 보관하세요.

> 참고: 사이트에서 추가한 기록은 브라우저의 로컬 저장 공간에 저장됩니다. GitHub 저장소나 다른 기기에 자동으로 동기화되지 않습니다. 브라우저 데이터를 지우기 전에 백업을 내려받으세요. 상장 사진 업로드는 아직 지원하지 않으므로 추후 기능으로 추가할 수 있습니다.

## GitHub Pages 공개하기
저장소가 `egiby4/egiby4.github.io`라면 GitHub Pages에서 공개할 수 있습니다.
1. 저장소의 **Settings → Pages**로 이동합니다.
2. **Build and deployment**에서 **Deploy from a branch**를 선택합니다.
3. Branch를 **main**, 폴더를 **/(root)**로 선택하고 저장합니다.
4. 배포가 완료되면 `https://egiby4.github.io/`에서 확인합니다.
